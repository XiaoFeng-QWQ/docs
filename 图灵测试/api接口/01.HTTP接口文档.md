# HTTP API 接口文档

> 项目：对面是AI吗（Turing Test Lobby）
> 后端：Swoole + MySQL / Redis / SQLite
> 接口基础地址：`https://service-game.xiaofengqwq.com`
> API 统一前缀：`/api/v1`
> 文档更新日期：2026-11-02

> 说明：页面与静态资源全部由前端构建产物提供，后端只保留 HTTP API 与 WebSocket。本文档依据当前 `Router.php` 与控制器实现重写，旧版无版本前缀路径（账号、海龟汤、2048、邮箱、贴纸、BOT 面板等）均已迁移或下线。

## 时间格式约定

所有接口返回的时间字段统一为 **Unix 秒级时间戳**（整数），由消费端自行格式化；历史数据库中的 `DATETIME` 文本在输出前会归一化。

```json
{
  "created_at": 1770257000,
  "last_played_at": 1770257000
}
```

## 认证机制

- 玩家身份使用 `Authorization: Bearer <player_token>`。
- Token 由 `base64(payload).HMAC-SHA256(payload, password_hash)` 组成，有效期 **365 天**；修改密码后签名密钥变化，旧 Token 立即失效。
- 获取 Token 的入口：
  - `POST /api/v1/auth`：`login_code`（邮箱验证码）、`login_password`（邮箱 + 密码）、`register`（验证码注册）。
  - OAuth：`POST /api/v1/oauth/exchange` 用一次性 code 换取 Token；`POST /api/v1/oauth/pending/{code}` 完成 OAuth 建号后直接返回 Token。
- 旧版「代号 + 密码」注册/恢复机制已下线；当前账号统一以邮箱为唯一凭据。

### 认证失败

缺少或无效 Token 时返回 HTTP 401：

```json
{
  "success": false,

}
```

## 通用响应格式

所有接口统一使用以下包络，**不再直接返回裸对象**：

成功（HTTP 200，创建类接口为 201）：

```json
{
  "success": true,
  "data": {
    "example": "value"
  }
}
```

失败（HTTP 400/401/403/404/405/409/429/500/503）：

```json
{
  "success": false,
  "error": "错误说明"
}
```

部分失败响应附带 `data`（例如验证码登录引导注册）：

```json
{
  "success": false,
  "error": "该邮箱尚未注册",
  "data": {
    "need_register": true,
    "email": "user@example.com",
    "suggested_nickname": "玩家1234"
  }
}
```

分页接口统一为 `data.items` + `data.pagination`，部分接口附带额外字段：

```json
{
  "success": true,
  "data": {
    "items": [],
    "pagination": {
      "page": 1,
      "page_size": 20,
      "total": 0,
      "total_pages": 0
    }
  }
}
```

### 通用错误码

| HTTP | 含义 |
|---|---|
| 400 | 参数缺失或格式错误 |
| 401 | 未登录 / Token 无效或过期 / OAuth 凭证失效 |
| 403 | 无权限、被封禁、BOT 未绑定或已禁用 |
| 404 | 资源不存在 |
| 405 | 路径存在但 HTTP 方法不允许（响应头带 `Allow`） |
| 409 | 冲突（昵称占用、重复申请、已公开、额度上限等） |
| 429 | 请求过于频繁 |
| 500 | 服务端异常 |
| 503 | 依赖服务（WebSocket/Redis 等）未就绪 |

## 1. 身份与账号

### 1.1 统一认证

`POST /api/v1/auth`

所有邮箱认证操作都通过 `action` 区分，请求体为 JSON。

| action | 用途 | 必填字段 | 登录态 |
|---|---|---|---|
| `send_code` | 发送邮箱验证码 | `email`，可选 `scene` | `bind_email` 场景需要 |
| `login_code` | 邮箱验证码登录 | `email`、`code`，可选 `fp` | 否 |
| `login_password` | 邮箱 + 密码登录 | `email`、`password` | 否 |
| `register` | 验证码注册并登录 | `email`、`code`、`nickname`、`password`，可选 `fp` | 否 |

#### action = send_code

```json
{
  "action": "send_code",
  "email": "user@example.com",
  "scene": "auth"
}
```

- `scene`：`auth`（登录/注册）或 `bind_email`（绑定/更换邮箱，需 `Authorization`）。
- 邮箱域名受黑白名单策略约束；绑定场景会校验邮箱是否已被其他账号占用。

**邮箱黑白名单**

- 白名单仅限制「新注册 / 绑定邮箱」，已有账号登录不受影响。`Mail.EmailWhitelist` 未配置时使用内置常见服务商（QQ、163、126、Gmail、Outlook 等）；配置为 `[]` 表示不限制；配置数组时支持子域名匹配。
- 黑名单复用 `Storage/blacklist.txt`，大小写不敏感、文件变更自动热更新：整行邮箱精确匹配，不含 `@` 的行按域名匹配，`@example.com` 形式按域名匹配。命中后发送验证码、登录/注册、绑定邮箱都会被拒绝。

响应：

```json
{
  "success": true,
  "data": {
    "cooldown": 60
  }
}
```

#### action = login_code

```json
{
  "action": "login_code",
  "email": "user@example.com",
  "code": "123456",
  "fp": "browser-fingerprint"
}
```

成功：

```json
{
  "success": true,
  "data": {
    "token": "eyJwbGF5ZXJfaWQiOiJwXzEyMyIsImV4cCI6MTgw... .签名",
    "nickname": "玩家小明",
    "player_id": "p_123",
    "email": "user@example.com",
    "password_set": true
  }
}
```

邮箱未注册时返回 HTTP 409，并携带注册引导数据：

```json
{
  "success": false,
  "error": "该邮箱尚未注册，请完成注册",
  "data": {
    "need_register": true,
    "email": "user@example.com",
    "suggested_nickname": "玩家1234"
  }
}
```

#### action = login_password

```json
{
  "action": "login_password",
  "email": "user@example.com",
  "password": "MyPass2026!"
}
```

成功时额外返回 `stats`（账号统计）：

```json
{
  "success": true,
  "data": {
    "token": "eyJ... .签名",
    "nickname": "玩家小明",
    "player_id": "p_123",
    "email": "user@example.com",
    "stats": {
      "id": "p_123",
      "nickname": "玩家小明",
      "discriminator": 1234,
      "created_at": 1770257000,
      "last_played_at": 1770257000,
      "turing_test": {},
      "total_games": 12,
      "win_rate": 58,
      "avg_msgs": 21
    },
    "password_set": true
  }
}
```

| 错误 | HTTP | 说明 |
|---|---|---|
| 邮箱格式不正确 / 请输入密码 | 400 | 参数问题 |
| 邮箱或密码错误 | 401 | 凭据错误 |
| 该账号尚未设置密码，请使用邮箱验证码登录 | 403 | OAuth 建号或随机密码账号 |
| 操作过于频繁，请稍后再试 | 429 | 同一账号连续失败限流 |

#### action = register

```json
{
  "action": "register",
  "email": "user@example.com",
  "code": "123456",
  "nickname": "玩家小明",
  "password": "MyPass2026!",
  "fp": "browser-fingerprint"
}
```

密码规则：至少 8 位、最多 72 字节，不能是纯数字、单字符重复、6 位以上连续字符或常见弱密码；不足 2 个汉字时需至少包含字母/数字/符号中的两类。规则**只约束新设置的密码**，存量老账号的弱密码仍可正常登录。

成功响应（HTTP 200，建号即登录）：

```json
{
  "success": true,
  "data": {
    "token": "eyJ... .签名",
    "nickname": "玩家小明",
    "player_id": "p_123",
    "email": "user@example.com",
    "password_set": true
  }
}
```

| 错误 | HTTP |
|---|---|
| 验证码错误或已过期 / 昵称过长 / 密码不符合规则 | 400 |
| 该邮箱已注册，请直接登录 / 该昵称已被占用 | 409 |
| 同 IP / 指纹注册数量超限或频率过高 | 429 |

> 同 IP、同指纹最多创建 3 个账号；注册与 OAuth 建号共用同一套限制。

`PATCH /api/v1/chat-history/{id}`

需要登录，只能修改自己的记录。`title` 与 `is_public` 至少传一个。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | string | 否 | 收藏标题，最长 100 字符 |
| `is_public` | bool | 否 | 是否公开；公开后生成/复用 `public_token` |

```json
{
  "title": "精彩的翻盘",
  "is_public": true
}
```

```json
{
  "success": true,
  "data": {
    "success": true,
    "message": "设置已更新",
    "public_token": "3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c",

```

## 3. 公开收藏与点赞

### 3.1 通过公开令牌查看收藏

`GET /api/v1/shared-collections/{token}`

无需登录。`token` 最长 64 字符。

返回结构同聊天记录详情（含 `messages`）；令牌不存在、已取消公开或已失效时返回 HTTP 404：

```json
{
  "success": false,
  "error": "该链接已失效或不存在"
}
```

### 3.2 点赞收藏

`POST /api/v1/collections/{id}/like`

需要登录。同一玩家对同一收藏只能点赞一次，不能取消。

```json
{
  "success": true,
  "data": {
    "success": true,
    "message": "已点赞"
  }
}
```

| 情况 | 响应（HTTP 200） |
|---|---|
| 收藏不存在或未公开 | `data.success=false`，`data.message=该收藏不存在或未公开` |
| 已经点过赞 | `data.success=false`，`data.message=已经点过赞了` |
| 幂等表写入异常 | `data.success=false`，`data.message=点赞失败` |

收藏 `id` 非正整数时返回 HTTP 400 `参数错误`。

## 6. 头像服务

`GET /api/v1/avatars/{player_id}`

公开接口，直接返回 WebP 图片二进制（`Content-Type: image/webp`），**不使用 JSON 包络**。

前端拼接 URL 示例（带版本参数避免缓存）：

```json

  "data": {}
}
```

**宏语法说明**

- 模板占位符为 `{参数名}`，展开时替换为调用方传入的内容。
- 支持列表参数与最多 3 层嵌套展开；最终展开长度受服务端限制。

## 15. OAuth 快捷登录

OAuth 仅作为登录/绑定入口，不使用 Cookie/Session；登录成功后仍发放玩家 Token。支持多 Provider（OIDC 自动发现或手写端点）。

| 常量 | 值 | 说明 |
|---|---|---|
| state TTL | 600 秒 | PKCE state 一次性 |
| pending TTL | 600 秒 | 未注册邮箱的建号确认 |
| exchange code TTL | 60 秒 | 一次性换取 Token |

### 15.1 可用 Provider 列表

`GET /api/v1/oauth/providers`

公开接口，仅返回已配置且端点可用的 Provider。

```json
{
  "success": true,
  "data": {
    "providers": [
      { "key": "github", "name": "GitHub" },
      { "key": "linuxdo", "name": "LINUX DO" }
    ]
```

### 15.2 发起 OAuth 授权

`GET /oauth/login/{provider}`

`POST /oauth/login/{provider}`

公开接口，**响应为 HTTP 302 跳转到第三方授权页，不使用 JSON 包络**。

| 参数 | 位置 | 必填 | 说明 |
|---|---|---|---|
| `provider` | path | 是 | Provider key |
| `redirect` | query/form | 否 | 登录成功后的站内路径，必须以 `/` 开头；非法值回退 `/` |
| `bind` | query/form | 否 | `1` 表示绑定模式 |
| `token` | form | 条件 | 绑定模式下无法带 `Authorization` 头时的玩家 Token |

- 绑定模式优先读取 `Authorization: Bearer`，其次读取表单 `token`；未登录返回 HTTP 401。
- Provider 不存在返回 HTTP 404 纯文本 `Unknown OAuth provider`。
- 授权地址生成失败返回 HTTP 500 纯文本提示。

### 15.3 OAuth 回调

`GET /oauth/callback/{provider}`

公开接口。校验 `code` 与 `state`、换取 access_token、拉取用户信息，然后：

1. 已绑定：生成一次性 exchange code，302 回 `{redirect}?oauth_code=...`。
2. 绑定模式：写入绑定并回跳 `{redirect}`。
3. 邮箱已匹配现有玩家：自动绑定并走登录流程。
4. 邮箱未匹配：生成 pending code，302 回 `{redirect}?pending_code=...`。
5. 其他失败：302 回 `{redirect}?oauth_error=...`。

| 情况 | HTTP |
|---|---|
| 缺少 code/state、state 无效或过期、Provider 不匹配 | 400 纯文本 |
| Provider 不存在 | 404 纯文本 |

|---|---|---|---|

## 17. 管理员登录

`POST /{AdminPath}/api/login`

`AdminPath` 由配置 `Admin.Path` 决定（默认 `admin`）。管理后台的页面与静态资源也由前端构建产物提供。

> 该接口沿用后台旧响应格式，**不使用 `success/data` 包络**，以 `ok` 表示结果。

```json
{
  "username": "admin",
  "password": "AdminPass2026!"
}
```

成功：

```json
{
  "ok": true,
  "token": "eyJ... .管理员签名",
  "username": "admin",
  "role": "super"
}
```

失败：

```json
{
  "ok": false,
  "error": "用户名或密码错误"
}
```

| 情况 | 响应 |
|---|---|
| 用户名或密码为空 | HTTP 200，`ok:false`，`error:用户名和密码不能为空` |
| 用户名或密码错误 | HTTP 200，`ok:false`，`error:用户名或密码错误` |
| 账号被禁用 | HTTP 200，`ok:false`，`error:该账号已被禁用` |
| 同用户名 + IP 连续失败 5 次 | HTTP 200，`ok:false`，提示剩余锁定秒数（锁定 5 分钟） |

管理员 Token 用于后台 API 与 `/{AdminPath}/ws` 通道，不属于玩家 Token 体系。
