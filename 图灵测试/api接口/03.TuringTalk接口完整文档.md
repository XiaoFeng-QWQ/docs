# TuringTalk 接口完整文档

> 服务地址：`https://game.xfcode.top`（WebSocket 对应 `wss://game.xfcode.top/...`）
> 消息格式：WebSocket 均为 JSON；HTTP 按 REST 风格。
> 更新日期：2026-10-06

---

# 一、WebSocket 接口

## 1.1 连接地址

服务端在 `onOpen` 时按连接的**路径**把连接分派给对应模式的 Handler；在 `onMessage` 时按消息 `type` 的**前缀**匹配路由（空前缀为兜底）。

| 模式 | WS 路径 | 消息前缀 | 说明 |
|------|---------|----------|------|
| 经典 1v1（图灵测试） | `/ws` | 空（兜底） | 匹配、聊天、判定 |
| 公共聊天室 | `/ws/lobby` | `lobby_` | 聊天、表情、图片、点歌、投票、管理 |
| 五子棋 | `/ws/board/gomoku` | `board_gomoku_` | 对弈 |
| 围棋 | `/ws/board/go` | `board_go_` | 对弈 |
| 海龟汤（真人房） | `/ws/soup` | `soup_` | 多人推理房 |
| 缘分（默契测试） | `/ws/fate` | `fate.` | 双人默契答题 |
| 方块世界（2D 沙盒） | `/ws/blockworld` | `bw_` | 多人建造 |
| 临时聊天 | `/ws/tempchat` | `temp_` | 1v1 私密房 |
| BOT 网关 | `/bot` | —（独立分派） | 开放给第三方 BOT 客户端 |
| 管理后台 | `/{Admin.Path}/ws`（默认 `/admin/ws`） | `admin_` | 管理员专属 |

> 说明：
> - 海龟汤、缘分受配置开关控制（`Soup.Enabled` / `Fate.Enabled`，默认 `true`）；关闭时对应 WS 路径不会注册。
> - **方块世界当前暂停开放**：`BlockWorld.Enabled` 配置为 `false`，此时 `/ws/blockworld` 通道不注册、`GET /blockworld` 返回 503 维护页、首页入口隐藏；世界数据保留，把配置改回 `true` 即可恢复。
> - 管理后台路径由 `Admin.Path` 配置（默认 `admin`），其 WS 地址为 `/{Admin.Path}/ws`。
> - 未匹配到路径的连接会兜底路由到 `/ws`。连接过载时服务端会下发 `{"type":"error","message":"服务器繁忙，请稍后再试"}` 并立即关闭。

**通用消息格式**（发送/接收均为 JSON）：
```json
{ "type": "消息类型", ...参数 }
```

**心跳**：除 BOT 网关（`bot_ping`/`bot_pong`）与临时聊天（`temp_ping`/`temp_pong`）外，其余模式统一使用 `ping`（C→S）与 `pong`（S→C）。

## 1.4 五子棋（`/ws/board/gomoku`，前缀 `board_gomoku_`）

棋类由公共基类 `AbstractBoardGameHandler` 统一处理，客户端发送的 `type` 需带前缀（如 `board_gomoku_join`）；服务端下发的 `type` 同样带前缀。

**客户端 → 服务端（公共动作）**

| type | 参数 | 说明 |
|------|------|------|
| `board_gomoku_join` | fp, nickname, password?, player_token? | 声明身份（进入棋局前必须先发） |
| `board_gomoku_create_room` | boardSize, firstMove(host/guest), mode?, timeLimit? | 创建房间（`firstMove` 决定房主执黑/白；其余字段原样存入对局 `settings`） |
| `board_gomoku_join_room` | roomId | 加入指定房间（座位已满则成为观战者） |
| `board_gomoku_cancel_wait` | — | 取消等待 |
| `board_gomoku_surrender` | — | 认输 |
| `board_gomoku_timeout` | — | 超时结算 |
| `board_gomoku_request_rematch` | — | 请求再来一局 |
| `board_gomoku_chat_message` | msg | 房间聊天 |
| `board_gomoku_share_invite` | — | 分享邀请到聊天室 |
| `board_gomoku_open_lobby_chat` / `board_gomoku_close_lobby_chat` | — | 打开/关闭聊天室浮层 |
| `board_gomoku_place_piece` | r, c | 落子（五子棋专属，0-based 行列） |
| `get_stickers` / `ping` | — | 通用（无前缀） |

**服务端 → 客户端**

| type | 说明 |
|------|------|
| `board_gomoku_connected` | 连接就绪 |
| `board_gomoku_joined` | 加入成功 |
| `board_gomoku_room_created` | 房间创建成功 |
| `board_gomoku_lobby_chat_result` | 聊天室浮层操作结果 |
| `board_gomoku_invite_result` | 分享邀请结果 |
| `board_gomoku_error` | 错误提示 |
| `board_gomoku_spectate_start` | 开始观战 |
| `board_gomoku_game_start` | 对局开始 |
| `board_gomoku_game_over` | 对局结束 |
| `board_gomoku_opponent_disconnected` | 对手断开 |
| `board_gomoku_chat_message` | 房间聊天广播 |
| `board_gomoku_piece_placed` | 落子广播（五子棋专属） |

> 棋盘类下发消息普遍把负载放在 `data` 字段内，例如：
> `{"type":"board_gomoku_piece_placed","data":{"r":7,"c":7,"color":1,"nextTurn":2}}`、
> `{"type":"board_gomoku_room_created","data":{"roomId":"A1B2C","color":1,"player_id":"..."}}`。

## 1.10 BOT 网关（`/bot`）

BOT 网关是开放给第三方 BOT 客户端的 WebSocket 入口，连接后需先鉴权，成功后自动加入聊天室，复用 `lobby_*` 全部消息能力（无需再发 `lobby_join`）。

**鉴权流程**：
```
客户端 → 服务端: 连接 /bot
服务端 → 客户端: {"type":"bot_wait_auth"}
客户端 → 服务端: {"type":"bot_auth","player_id":"xx","key":"xx"}
服务端 → 客户端: {"type":"bot_auth_ok","nickname":"xx"} 或 {"type":"bot_error","message":"..."}
```

| type | 方向 | 参数 | 说明 |
|------|------|------|------|
| `bot_auth` | C→S | player_id, key | 鉴权 |
| `bot_ping` | C→S | — | 心跳 |
| `bot_wait_auth` | S→C | — | 等待鉴权 |
| `bot_auth_ok` | S→C | nickname | 鉴权成功 |
| `bot_pong` | S→C | — | 心跳响应 |
| `bot_error` | S→C | message | 鉴权失败/错误 |

> 鉴权失败文案：`BOT 鉴权失败：玩家ID或KEY不正确`；未鉴权即发其它消息时提示 `请先发送鉴权消息 bot_auth`。

# 三、通用说明

- **身份**：玩家通过 `player_token` 或 `player_id` + 密码验证；聊天室同时使用 `nickname`。BOT 使用独立账户 ID（`bot_account_id`，复用玩家身份体系）并需 `player_id` + `key` 鉴权。
- **管理员**：登录 `/{Admin.Path}` 获取 JWT token（HMAC-SHA256），聊天室通过 `lobby_admin_verify`、管理后台通过 `admin_connect` 验证。
- **心跳**：`ping` / `pong`（BOT 为 `bot_ping`/`bot_pong`，临时聊天为 `temp_ping`/`temp_pong`），超时自动清理连接。
- **路由**：WS 连接按路径分派 Handler；消息按 `type` 前缀匹配（空前缀兜底）。`admin_connect`、`ping`、`pong` 在分发前被特判处理。
- **权限**：管理员操作（ban/mute/isolate/kick/delete 等）服务端强制校验 `isAdmin`。
- **封禁**：IP + 指纹 + player_id 三维，所有模式接入检查（含图片上传接口）。
- **防刷**：同 IP/指纹最多 3 账号，创建频率 10 分钟限 1 次；聊天室发言有频率限制，图片上传 60 秒内最多 10 次。
- **时间字段**：全站统一为 Unix **秒级**时间戳（`time` / `created_at`），展示格式由消费端自行解析。
- **开关配置**：海龟汤、缘分、方块世界分别受 `Soup.Enabled`、`Fate.Enabled`、`BlockWorld.Enabled` 控制；关闭时不注册对应路由。
