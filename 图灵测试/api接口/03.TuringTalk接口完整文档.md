# TuringTalk 接口完整文档

> 服务地址：`http://192.168.1.61:9502`（默认端口 9502）
> 消息格式：WebSocket 均为 JSON；HTTP 按 REST 风格。

---

# 一、WebSocket 接口

## 1.1 连接地址

| 模式 | WS 地址 | 说明 |
|------|---------|------|
| 经典 1v1（图灵测试） | `ws://host/ws` | 匹配、聊天、判定 |
| 公共聊天室 | `ws://host/ws/lobby` | 聊天、表情、点歌、管理 |
| WhoisAI 多人模式 | `ws://host/ws/WhoisAI` | 多人混战 |
| 五子棋 | `ws://host/ws/gomoku` | 对弈 |
| 管理后台 | `ws://host/ws/admin` | 管理员专属 |

**通用消息格式**（发送/接收均为 JSON）：
```json
{ "type": "消息类型", ...参数 }
```

# 三、通用说明

- **身份**：玩家通过 `player_token` 或 `player_id` + 密码验证；聊天室同时用 `nickname`
- **管理员**：登录 `/admin` 获取 token，聊天室通过 `lobby_admin_verify` 验证
- **心跳**：`ping` / `pong`，超时自动清理
- **权限**：管理员操作（ban/mute/isolate/delete 等）服务端强制校验 `isAdmin`
- **封禁**：IP + 指纹 + player_id 三维，所有模式接入检查
- **防刷**：同 IP/指纹最多 3 账号，创建频率 10 分钟限 1 次
