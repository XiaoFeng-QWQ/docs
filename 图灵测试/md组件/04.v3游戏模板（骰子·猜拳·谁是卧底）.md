# v3 游戏模板（骰子 · 猜拳 · 谁是卧底）

> 全部模板使用 v3 语法，**复制即用**。
> 谁是卧底模板只需修改第一行玩家名单、身份牌与两个词即可开局。

## 🎲 一、骰子

### 1.1 单骰 1d6

```md
[!按钮:🎲 掷 1d6|随机:骰=1,6&发送:🎲 你掷出了 {骰} 点]
```

### 1.2 双骰 2d6（自动求和）

```md
[!变量:总=0]
[!按钮:🎲 掷 2d6|随机:骰1=1,6&随机:骰2=1,6&变量:总={骰1}+{骰2}&发送:🎲 {骰1} + {骰2} = {总}]
```

### 1.3 1d20 检定（带结果判定）

```md
[!按钮:🎯 1d20 判定|随机:判定=1,20&发送:🎯 检定结果：{判定}]
[!条件:{判定}>=15|✅ 大成功！]
[!条件:{判定}>=10|👍 成功]
[!条件:{判定}<10|❌ 失败...]
```

### 1.4 多骰子（循环掷 N 个）

```md
[!变量:总=0]
[!按钮:🎲 掷 3d6|循环:i=1;i<4;i=i+1;随机:骰{i}=1,6&变量:总={总}+{骰{i}}&发送:🎲 第{i}个：{骰{i}}
🎯 合计：{总}]
```

## 🕵️ 三、谁是卧底（标准 5 人局）

> 🖊️ **只需修改玩家名单、身份牌与两个词**即可开局（公开分配版，适合熟人局 / 法官主持）。

```md
# 🕵️ 谁是卧底 v3 模板
[!变量:玩家=小攸/小喵/小汪/小明/小红]      ← 🖊️ 修改玩家名单
[!变量:身份=平民/平民/平民/平民/卧底]      ← 🖊️ 身份牌（数量=玩家人数，卧底 1 个；可改 2 个）
[!变量:平民词=牙膏]                        ← 🖊️ 平民词
[!变量:卧底词=洗面奶]                      ← 🖊️ 卧底词（与平民词相近但不同）

🕵️ 开局发牌：
[!按钮:🎭 发牌|洗牌:身份&弹窗:🕵️ 谁是卧底 · 身份表|按顺序对应：
{玩家}
→
{身份}

📝 平民词：{平民词}
🕵️ 卧底词：{卧底词}]

🗣️ 描述环节（每人轮流一句话描述自己的词，**禁止说出词本身或同字**）：
[!倒计时:30秒|id=轮次|绑定=1|end=发送:🔄 下一位描述！|lock=局]

🗳️ 投票环节：
[!投票:🕵️ 这轮投谁出局|{玩家}]
[!倒计时:2分|id=投票|绑定=1|end=发送:⏰ 投票截止！法官请公布票数最高者出局|lock=局]

🏁 结算（法官按实际结果点）：
[!按钮:🚨 卧底被投出|发送:🏆 平民胜利！卧底「{卧底词}」被揪出来了！]
[!按钮:🕵️ 卧底获胜|发送:🕵️ 卧底胜利！「{卧底词}」卧底坚持到了最后！]
```

### 玩法说明

1. **发牌**：点「🎭 发牌」→ 身份随机洗牌，弹窗显示 玩家 → 身份 对应表 + 平民词/卧底词（玩家按自己身份看对应词）
2. **描述**：每人轮流 30 秒描述自己的词，不能说词本身 / 同字（违规由法官判定）
3. **投票**：所有人投出最可疑的人，票数最高者出局（法官主持唱票）
4. **胜负**：卧底被投出 → 平民胜；卧底活到最后（剩 2~3 人）→ 卧底胜
5. **身份私密性**：当前为公开分配版（适合熟人局）；私密身份需按钮权限（v3.5 规划中）

## 🧩 附：游戏常用组件速查

```md
# 随机数
随机:名=最小,最大

# 随机分组 / 抽签
洗牌:名单,取1          ← 抽 1 人
洗牌:名单,取2          ← 抽 2 人（名单缩短，不重复）

# 倒计时
[!倒计时:90|id=名|绑定=1|end=动作|lock=组]  ← 必须绑定启动（v3.6 防刷屏）
[!按钮:开始|倒计时:名]

# 投票（多选/权限/选项洗牌）
[!投票:问题|选项1|选项2|多选=2|洗牌|perm=@小攸]

# 点击限制
click=*1   每人一次　　click=1   所有人一次
```
