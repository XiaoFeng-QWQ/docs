# 聊天室 MD 格式完整教程（v3 标准）

> 本教程详细讲解聊天室（Lobby）支持的 **v3 扩展语法**，包括**标准 Markdown** 和**聊天室扩展组件**。
> 所有示例均可直接复制到聊天室测试。
> 语法规范详见《MD扩展语法规范v3.md》（**v3.7**）。
> **v3.7 内容换行**：组件内容文本中 `\n` 转真实换行（`\\n` 转义保留字面）；定时组件未绑定且 end 含 `发送:` 不自动启动（需按钮 `定时:名` 手动启动）。
> **v3.6 防刷屏**：倒计时/计时器必须 `绑定=1` 启动；动作链未绑定且含 `发送:` 不自动启动；变量组件隐藏不显示值。

## 一、标准 Markdown 语法

聊天室使用 marked（GFM 模式）渲染标准 Markdown。

```markdown
# 一级标题
**粗体文字**　*斜体文字*　~~删除线文字~~
> 引用文字　`行内代码`
- 无序列表　1. 有序列表
- [x] 已完成　- [ ] 未完成
[点击访问](https://example.com)
| 列1 | 列2 |
|-----|-----|
| a   | b   |
```

> ⚠️ 消息内禁止图片（防流量攻击）；图片仅在**弹窗内容**里允许（png/jpg/gif/webp/bmp/svg/ico）。

---

### 1.10 回复引用（聊天室通用）

回复消息时引用块自动处理：

- **引用文本过长**：超过 60 字自动截断 + 省略号（`...`）
- **引用 MD/特殊格式消息**：显示「特殊格式不支持预览」（不解析组件语法）
- 引用表情消息：显示表情图片

## 二、扩展语法基础结构

v3 所有扩展组件统一单层格式：

```
[!类型:内容|键=值|键=值|...]
```

| 部分 | 说明 | 必填 |
|------|------|------|
| `[!` | 组件标记（普通 `[...]` 文本不解析） | 是 |
| `类型` | 组件类型（中文，如 文本/按钮/投票/画板） | 是 |
| `内容` | 该类型的核心参数（第一个冒号后） | 是 |
| `键=值` | 命名参数，`\|` 分隔，顺序任意 | 否 |

**规则**：
- `|` 是参数分隔符，参数值内不能包含未转义的 `|`
- 状态（输入/开关/变量）**仅当前消息内有效**
- 单条消息长度上限 **4000 字符**
- 所有展示文本自动 HTML 转义（防注入）

```markdown
[!文本:你好]                        ← 最简
[!输入:占位符|id=name]              ← 带命名参数
[!按钮:开始|发送:开打！]             ← 动作按钮
[!倒计时:90|id=t|绑定=1|end=发送:时间到！]  ← 组合参数
[!按钮:开始倒计时|倒计时:t]
```

## 三、展示组件

| 组件 | 语法 | 说明 |
|------|------|------|
| 文本 | `[!文本:内容\|#f00\|大]` | 彩色文本；`大`/`小` 显式档位；**无显式按长度自适应**（字号短大长小 + 宽度按字数限宽换行） |
| 画板 | `[!画板\|图形序列]` | 纯展示画板（不响应点击） |
| 表格 | `[!表格:列数\|表头\|数据...]` | 自定义表格 |
| 音乐 | `[!音乐:URL\|标题=歌名\|id=名\|状态=变量名]` | 音乐播放器（`状态=` 输出播放/暂停/结束到变量） |
| 图集 | `[!图集:标题\|URL1\|URL2\|...\|自动=秒\|id=名]` | 图集轮播弹窗（`id=` 供 `洗牌:图集,名` 引用洗图） |
| 投票 | `[!投票:问题\|选项1\|选项2\|...]` | 投票（多选/权限/洗牌） |
| 进度 | `[!进度:7/10\|id=名]` | 进度条 |
| 倒计时 | `[!倒计时:90\|id=名\|绑定=1\|end=动作\|lock=组\|bar=进度条id]` | 倒计时（**必须绑定启动**（v3.6 防刷屏）/锁定按钮组/进度联动） |
| 计时 | `[!计时:25分\|id=名\|绑定=1\|end=动作\|重复=1]` | 正向计时器（**必须绑定启动**（v3.6 防刷屏）/到点动作/自动重复） |
| 定时 | `[!定时:09:00\|动作\|重复=1\|绑定=1]` | 定时到点执行动作（**绑定=1 自动启动**；未绑定且动作含 `发送:` 不自动启动（v3.7 防刷屏），需按钮 `定时:名` 手动启动） |

```markdown
[!文本:🎉 欢迎|#f00|大]
[!进度:7/10|id=血条]
[!倒计时:5分|id=茶|绑定=1|end=发送:茶泡好了！]
[!按钮:泡茶|倒计时:茶]
[!投票:今晚吃什么|火锅|烧烤|日料|多选=2]
```

## 四、交互组件

| 组件 | 语法 | 说明 |
|------|------|------|
| 按钮 | `[!按钮:文字\|URL]` | 跳转按钮（URL 可省） |
| 按钮动作 | `[!按钮:文字\|发送:内容]` | 动作按钮（见第六章） |
| 发送 | `[!发送:文字\|内容]` | 点击把内容填入输入框并发送 |
| 复制 | `[!复制:文字\|内容]` | 点击复制到剪贴板 |
| 弹窗 | `[!弹窗:标题\|内容]` | 弹窗（内容可含组件/图片） |
| 确认 | `[!确认:提示语\|动作]` | 先确认再执行动作 |
| 输入 | `[!输入:占位符\|id=名]` | 输入框，值存入 `{名}` |
| 显示 | `[!显示:名]` | 实时显示输入/开关/变量值 |
| 开关 | `[!开关:值1/值2\|id=名\|on=动作]` | 点击切换值，可联动动作 |
| 隐藏 | `[!隐藏:文字\|动作]` | 无按钮样式，点击执行动作 |

```markdown
[!输入:输入昵称|id=昵称]　[!显示:昵称]
[!开关:开/关|id=灯|on=发送:灯被切到{灯}]
[!确认:确定删除？|发送:已删除]
[!复制:复制邀请码|INVITE-2026]
```

## 五、逻辑组件

| 组件 | 语法 | 说明 |
|------|------|------|
| 变量 | `[!变量:名=值]` | 定义变量（隐藏，`{名}` 引用） |


## 六、动作体系

动作是按钮/开关/倒计时等组件的"执行体"，统一 `前缀:内容`：

```
发送:内容              填入输入框并发送
复制:内容              复制到剪贴板
弹窗:标题|内容          打开弹窗（内容可含组件）
跳转:URL               新标签页打开
开关:名                切换指定开关到下一个值
显示:名 / 隐藏:名       显示/隐藏指定组件（按 id）
倒计时:名              启动指定倒计时
计时:名                启动指定计时器
变量:名=值             设置变量（支持 {引用} 与数学表达式）
循环:变量=起始;条件;步进;动作体   循环执行动作（上限 300 次）
洗牌:名                打乱列表值写回（随机）
洗牌:名,取N            打乱后取前 N 个写回（抽签/随机点名）
洗牌:名1;名2,取N       多值合并打乱抽 N（随机分组）
洗牌:图集,名           随机打乱图集图片顺序
随机:名=最小,最大      生成随机整数写回（闭区间）
等待:秒               延时等待后继续
分支:{名}=值1→动作1;值2→动作2;其他→动作   多分支选择执行
动作链:名,开始/暂停/继续/停止/重播   控制动作链
音乐:名[,播放/暂停/停止]   控制音乐播放器
```

```markdown
[!按钮:掷骰子|随机:骰=1,6&发送:你掷出了 {骰} 点]
[!按钮:抽奖|洗牌:名单,取1&弹窗:🎁 中奖者|{名单}]
[!按钮:翻页|变量:页=取余({页}+1,10)]
[!按钮:行动|分支:{选择}=1→发送:⚔️ 攻击;2→发送:🛡️ 防御;其他→发送:无效]
```

## 七、条件动作与动作串

任意动作可带条件后缀，满足才执行：

```
动作?条件
动作?条件:否则动作
```

- `?` 分隔动作与条件（如提问）；`:` 分隔否则动作
- 条件支持：`{名}` 非空、`= != > >= < <=`、`~`（列表包含）
- 成功/失败分支可嵌套条件动作（≤3 层）
- `&` 连接多个动作顺序执行（动作串）

```markdown
[!开关:🦔|on=变量:分数={分数}+10?{洞1}=1:发送:打空了！]
[!按钮:签到|发送:签到成功&变量:天数={天数}+1?{已签}!=1:发送:今天已签过啦！]
[!按钮:攻击|随机:伤害=5,15&变量:血量={血量}-{伤害}?{血量}>10:发送:⚠️ 倒下了]
[!按钮:结算|变量:分数={分数}+10?{分数}>=100:变量:分数={分数}+5?{分数}>=60:发送:不及格]
```

## 八、值引用与数学

### 8.1 变量引用

```
{名}          引用输入框/开关/变量的当前值
{名|默认值}    引用为空时显示默认值
```

列表值用 `/` 或 `,` 分隔，在列表型参数中自动展开：

```markdown
[!变量:菜单=火锅,烧烤,日料]
[!投票:今晚吃什么|{菜单}]          ← 展开为 3 个选项
[!变量:图库=https://a.png,https://b.png]
[!图集:我的图库|{图库}]            ← 展开为 2 张图
```

### 8.2 数学表达式与函数

```
+ - * / ( ) 四则运算
取余({a},{b})  取整({x})  绝对值({x})  最大({a},{b})  最小({a},{b})
```

```markdown
[!按钮:加5|变量:金币={金币}+5]
[!按钮:翻页|变量:页=取余({页}+1,10)]
[!按钮:保底|变量:伤害=最大(0,{攻击}-{防御})]
```

## 九、通用参数

### 9.1 颜色（裸色简写）

```markdown
[!文本:你好|#f00]           ← 红色（3 位/6 位 hex 均可）
[!按钮:确定|#0f0]           ← 按钮也支持
[!文本:大号居中|#f00|大]
```

### 9.2 统一 ID

所有组件支持 `id=名`：渲染时注入 `data-ui-id`，供动作链目标、`显示:`/`隐藏:` 按 id 操作。同一消息内唯一。

```markdown
[!文本:标题|id=标题]
[!动作链:目标=标题;颜色=#f00;延时=300|循环]
```

### 9.3 点击次数限制 `click`

| 写法 | 含义 |
|------|------|
| `click=*1` | **每人**只能点 1 次 |
| `click=*5` | 每人独立 5 次 |
| `click=1` | **所有人合计**只能点 1 次 |
| `click=@张三:2` | 仅张三 2 次，其他人无限 |
| `click=5@张三:2` | 全局 5 次 + 张三 2 次 |

```markdown
[!按钮:签到|发送:签到成功|click=*1]     ← 每人只能签到一次
[!按钮:开抢|发送:我抢到了！|click=1]     ← 所有人只能抢一次
```

---

### 9.4 弹窗内定位（x/y，v3.5 新增）

组件支持 `x=数字` / `y=数字` 偏移（px，可负值），相对自身流位置定位，手机/电脑显示位置一致：

```markdown
[!按钮:🌟|id=星|x=10|y=5]
```

## 十、游戏组件

### 10.1 动作链（隐形编排器）

```
[!动作链:步骤1/步骤2|循环=N|id=名|绑定=1]

步骤 = 目标=组件id;操作;延时=毫秒;条件=表达式;跳转=步骤号（步骤内 `;` 分隔）
```

- 双 ID：`目标=组件id` 操作对象；`id=链名` 对外接口
- 触发：省略 `绑定=` 自动；`绑定=1` 等外部触发（按钮/倒计时/开关/确认/条件/其他链）；**v3.6 防刷屏：未绑定且含 `发送:` 步骤的不自动启动，必须绑定**
- 操作集：`移动x/y` `缩放` `旋转` `透明` `闪烁` `颜色` `文字` `隐藏/显示` `状态` `变量` `音效` `更新`（画板重绘）任意 v3 动作
- 循环在**消息可见时**才跑，划出视口暂停

```markdown
[!动作链:目标=标题;闪烁=3;延时=200|id=开场|绑定=1]
[!倒计时:5|id=开打计时|绑定=1|end=动作链:开场,开始&发送:开打！]
[!按钮:开始|倒计时:开打计时]
[!按钮:⏸ 暂停|动作链:跳动,暂停]
```

## 十一、完整示例合集

```markdown
# 🎲 骰子
[!按钮:🎲 掷 1d6|随机:骰=1,6&发送:🎲 你掷出了 {骰} 点]

# 🎲 双骰
[!按钮:🎲 掷 2d6|随机:骰1=1,6&随机:骰2=1,6&变量:总={骰1}+{骰2}&发送:🎲 {骰1}+{骰2}={总}]

# ✂️ 猜拳（电脑随机）
[!按钮:✌️ 剪刀|随机:电脑=1,3&发送:✌️ 剪刀 vs 剪刀 → 🤝 平局?{电脑}=1:发送:✌️ 剪刀 vs 石头 → 💔 输了?{电脑}=2:发送:✌️ 剪刀 vs 布 → 🎉 赢了]
[!按钮:✊ 石头|随机:电脑=1,3&发送:✊ 石头 vs 石头 → 🤝 平局?{电脑}=2:发送:✊ 石头 vs 布 → 💔 输了?{电脑}=3:发送:✊ 石头 vs 剪刀 → 🎉 赢了]
[!按钮:🖐 布|随机:电脑=1,3&发送:🖐 布 vs 布 → 🤝 平局?{电脑}=3:发送:🖐 布 vs 剪刀 → 💔 输了?{电脑}=1:发送:🖐 布 vs 石头 → 🎉 赢了]

# 📢 每人只能点一次
[!按钮:签到|发送:✅ 签到成功！|click=*1]

# 🔒 所有人只能点一次
[!按钮:抢沙发|发送:🧨 我是第一个！|click=1]
```
