# 聊天室 MD 消息扩展编写规则（v2 标准）

> 本文档定义聊天室（Lobby）Markdown 消息扩展的**统一编写规范**。
> 所有新增的按钮、输入框、变量、倒计时等交互组件，必须遵循本规则。
> 本规则适用于：普通聊天消息、弹窗内容、回复引用等所有经过 `mdFormat` 渲染的文本。

---

## 一、设计原则

1. **统一结构**：所有扩展组件统一使用 `[!文本](类型:参数)` 结构。
2. **统一参数**：命名参数一律用 `键=值`，多个参数用 `|` 分隔。
3. **统一引用**：变量/组件值引用统一用 `%名称%`（兼容 `{名称}`）。
4. **统一操作**：动作统一写成 `操作名:参数`。
5. **作用域隔离**：所有状态（变量、输入框、倒计时）**仅当前消息内有效**，不跨消息。
6. **安全优先**：外部输入必须转义；图片/音频 URL 必须过白名单校验。

---

## 二、基础语法结构

```
[!显示文本](类型:主参数|键1=值1|键2=值2|...)
```

| 部分 | 说明 | 示例 |
|------|------|------|
| `显示文本` | 组件上显示的文字（必填） | `点我` |
| `类型` | 组件类型（见第三章） | `send` |
| `主参数` | 该类型的核心参数（第一个，无键名） | `你好` |
| `键=值` | 命名参数，可多个，顺序任意 | `id=foo`、`ok=答案` |

示例：
```markdown
[!发送](send:你好|id=btn1)
[!输入](input:请输入|id=name|ok=张三)
```

**约定**：
- 类型名统一为**小写单词**，不重复带后缀（如 `ok` 而非 `okbtn`、`if` 而非 `showif`）。
- `|` 是参数分隔符，**参数值内不得包含 `|`**（如需展示 `|` 用 `%7C` 或换词）。
- 参数键名用小写，多词用 `.` 连接（如 `bar.add`、`timer.end`）。

## 三、组件类型总览

### A. 动作类（点击触发动作）

| 类型 | 作用 | 主参数 | 典型用法 |
|------|------|--------|----------|
| `btn` | 跳转链接 | URL | `[!官网](btn:https://example.com)` |
| `send` | 发送消息 | 消息内容 | `[!发送](send:你好)` |
| `copy` | 复制内容 | 内容 | `[!复制](copy:文字)` |
| `modal` | 打开弹窗 | 标题`|`内容 | `[!详情](modal:标题|内容)` |
| `embed` | 内嵌网页 | URL | `[!预览](embed:https://example.com)` |
| `confirm` | 确认后执行 | 提示语`|`动作 | `[!删除](confirm:确定吗?|send:已删除)` |
| `details` | 折叠面板 | 标题`|`内容 | `[!展开](details:更多|隐藏内容)` |
| `rand` | 随机发送/弹窗 | 值1`|`值2`|`... | `[!抽一个](rand:你好|哈哈|嗨)` |
| `ok` | 校验输入后执行 | 输入框id | `[!确认](ok:ans|right=动作|wrong=动作)` |
| `cancel` | 取消/执行动作 | 动作(可空) | `[!取消](cancel:)` |
| `close` | 关闭组件/交互区 | 动作(可空) | `[!关闭](close:)` |
| `switch` | 可改变内容 | 值1`|`值2`|`... | `[!选项](switch:A|B|C|id=sel)` |
| `hide` | 隐藏按钮（无外观但可点） | 动作 | `[!点这里](hide:send:你好)` |

### B. 展示/交互类（渲染内容）

| 类型 | 作用 | 主参数 | 典型用法 |
|------|------|--------|----------|
| `input` | 输入框 | 占位符 | `[!输入](input:请输入|id=name)` |
| `get` | 显示输入框内容 | 输入框id | `[!显示](get:name)` |
| `var` | 显示变量值 | 变量名 | `[!变量](var:score|init=0)` |
| `def` | 隐藏定义值 | 变量名 | `[!定义](def:url|init=https://x.com)` |
| `cipher` | 加密内容 | 明文 | `[!查看](cipher:秘密|key=暗号)` |
| `table` | 表格 | 单元格... | `[!表格](table:col=3|表头1|表头2|表头3|数据...)` |
| `music` | 音频播放器 | 音频URL | `[!试听](music:https://x.com/a.mp3|t=标题)` |
| `timer` | 倒计时 | 秒数 | `[!倒计时](timer:30|id=t1|end=动作)` |
| `bar` | 进度条 | 当前值`/`最大值 | `[!进度](bar:50/100|id=bp)` |
| `if` | 条件显示 | 条件 | `[!结果](if:ans=42|then=内容)` |
| `text` | 文本框（带样式显示） | 文本内容 | `[!公告](text:维护中|t=公告\|style=warn)` |
| `board` | 画板（SVG 绘图） | 画板大小(1-20) | `[!画板](board:20|shapes=rect:2,2,5,3:#0f0)` |
| `vote` | 投票（本地计数） | 问题`|`选项1`|`选项2... | `[!投票](vote:选哪个?|A|B|C|id=v1)` |
| `dice` | 骰子（XdY±Z） | 骰子表达式 | `[!掷骰](dice:2d6+3|id=d1)` |
| `at` | 定时到点 | `HH:MM[:SS]` | `[!定时](at:21:30|end=send:到点啦)` |
| `gallery` | 图集轮播 | 标题`|`url1`|`url2... | `[!图集](gallery:风景|https://x.com/a.png|https://x.com/b.png)` |

## 四、各类型详细规则

### 4.1 输入框 `input`
```
[!标题](input:占位符|id=名称|ok=期望值|on=动作|color=颜色)
```
- `占位符`：未输入时的灰色提示（可空）
- `id`：输入框标识（**必填**，供 `get`/`ok`/`%名称%` 引用）
- `ok`：期望的正确内容（配合 `ok` 按钮校验）；**多答案用 `/` 分隔**，任一匹配即正确（如 `ok=红/蓝/绿`）
- `on`：输入变化时自动执行的动作（联动）
- `color`：颜色（可被 switch 绑定）

示例：
```markdown
[!答案](input:请输入答案|id=ans|ok=42)
```

### 4.2 显示内容 `get`
```
[!占位](get:组件id|color=颜色)
```
- 实时显示指定组件的值（**输入框内容 / 变量值 / switch 当前值**均可，仅当前消息内）

### 4.3 确认校验按钮 `ok`
```
[!确认](ok:输入框id|right=动作|wrong=动作|lock=组名)
```
- 点击后：输入框内容 === `ok` 期望值 → 执行 `right`；否则执行 `wrong`
- `lock`：倒计时锁定组（倒计时期间禁用）

### 4.4 取消 / 关闭
```
[!取消](cancel:动作)      ← 点击执行动作（可空）
[!关闭](close:动作)       ← 点击执行动作（可空）
```
- `cancel:` 空参数 = 仅一个"取消"按钮（不做事）
- 动作写法见第七章

### 4.5 可改变内容 `switch`
```
[!标签](switch:值1|值2|值3|id=名称|color=颜色模式|cc=颜色1/颜色2/...|on=动作|lock=组)
```
- 点击循环切换 `值1 → 值2 → 值3 → 值1`
- `color=1`：颜色模式（背景色跟随）
- `cc=#f00/#0f0/#00f`：独立颜色列表（`/` 分隔，与值一一对应，内容颜色同切）
- `on`：切换时触发动作（联动）

### 4.6 变量 `var` / 定义 `def`
```
[!显示](var:变量名|init=初始值)      ← 显示变量值
[!定义](def:变量名|init=内容)        ← 隐藏定义，不占空间
```
- 变量值通过操作修改（`set`/`incr`/`decr`）
- 任何地方用 `%变量名%` 引用
- `def` 不渲染可见内容，仅注册变量

### 4.7 加密 `cipher`
```
[!查看](cipher:明文内容|key=密钥)
```
- 渲染时加密存储（F12 看到密文），点击解密弹窗显示

### 4.8 表格 `table`
```
[!表格](table:col=列数|表头1|表头2|...|单元格...)
```
- 首行 `col=N` 个单元格为表头，之后按 N 个一行
- 单元格支持 `%值%` 引用（def/var/switch/输入框），渲染后自动替换

### 4.9 音乐播放器 `music`
```
[!试听](music:音频URL|t=标题)
```
- URL 白名单：`mp3|wav|ogg|aac|m4a|flac|opus|webm|weba|wma|mid|midi`（带 `?` 参数也可）
- 非法链接渲染为 `[音频链接不合法]`

### 4.10 倒计时 `timer`
```
[!倒计时](timer:秒数|id=名称|end=动作|lock=组名|bar=进度条id)
```
- 渲染后自动开始倒数
- `end`：倒数到 0 时执行动作
- `lock`：锁定组内按钮（`lock=组名`），倒计时结束才可操作
- `bar`：联动进度条（每秒同步减少）

### 4.11 进度条 `bar`
```
[!进度](bar:当前值/最大值|id=名称)
```
- 通过操作增减：`bar.add:id=值`、`bar.sub:id=值`、`bar.set:id=值`

### 4.12 条件显示 `if`
```
[!条件](if:条件|then=显示内容)
```
- 条件格式（支持比较运算符）：
  | 写法 | 含义 |
  |------|------|
  | `id` | 非空即显示 |
  | `id=期望值` / `id==期望值` | 相等才显示 |
  | `id!=期望值` | 不相等才显示 |
  | `id>数字` / `id>=数字` / `id<数字` / `id<=数字` | 数值比较（非数字不满足） |
- 条件来源：输入框内容 / 变量值 / switch 当前值
- 条件变化时自动刷新显示/隐藏
```markdown
[!结果](if:score>=60|then=✅ 及格！)
[!警告](if:hp<30|then=⚠️ 血量告急！)
```

### 4.13 隐藏按钮 `hide`
```
[!文字](hide:动作)
```
- 外观为普通文字（下划线虚线），无按钮样式
- 点击执行动作（`send:`/`copy:`/`switch:` 等）
- **不能**使用 `color`（不改变颜色）

### 4.14 文本框 `text`
```
[!标题](text:内容|t=标题|color=前景色|color.bg=背景色|align=left|size=md|style=note)
```
| 参数 | 说明 | 示例 |
|------|------|------|
| 主参数 | 文本内容 | `text:维护中` |
| `t` | 标题 | `t=公告` |
| `color` / `color.bg` | 文字/背景色 | `color=#f00\|color.bg=#ffe0e0` |
| `align` | 对齐（left/center/right） | `align=center` |
| `size` | 字号（sm/md/lg） | `size=lg` |
| `style` | 样式（note/info/warn/success/danger） | `style=warn` |

> 内容支持 `%值%` 引用（def/var/switch/输入框），渲染后自动替换。

```markdown
[!公告](text:服务器维护中|t=📢 公告|align=center|size=lg|style=warn)
```

### 4.15 画板 `board`
```
[!标题](board:大小|shapes=图形定义|text=文本|bg=背景色|grid=0|id=名称|modal=1|hide=1)
```
| 参数 | 说明 | 示例 |
|------|------|------|
| 主参数 | 画板大小（**1-20**，最大 20×20 方形） | `board:20` |
| `shapes` | 图形定义（`;` 分隔多个图形） | `shapes=rect:2,2,5,3:#0f0` |
| `text` | 画板内文本（默认居中、字号=尺寸/8、黑色） | `text=我家` |
| `tx` / `ty` | 文本位置坐标（省略=居中） | `tx=5\|ty=3` |
| `ts` | 文本字号（省略=默认） | `ts=2` |
| `tc` | 文本颜色（省略=黑） | `tc=#ff0000` |
| `bg` | 背景色 | `bg=#e0f2fe` |
| `grid` | 网格线显示（`0` 关闭，默认显示） | `grid=0` |
| `id` | 画板标识（联动开关用） | `id=map` |
| `modal=1` | 内置到弹窗（点击按钮显示） | `modal=1` |
| `hide=1` | 初始隐藏 | `hide=1` |

**图形语法**（`类型:坐标:颜色`，多个用 `;` 分隔）：
| 图形 | 语法 | 示例 |
|------|------|------|
| 线条 | `line:x1,y1,x2,y2` | `line:0,0,10,10:#f00` |
| 矩形 | `rect:x,y,w,h` | `rect:2,2,5,3:#0f0` |
| 圆 | `circle:cx,cy,r` | `circle:5,5,3:#00f` |
| 点 | `dot:x,y` | `dot:3,4:#000` |
| 三角形 | `triangle:x1,y1,x2,y2,x3,y3` | `triangle:0,0,10,0,5,8:#f80` |
| 菱形 | `diamond:cx,cy,r` | `diamond:10,10,5:#0ff` |
| 五角星 | `star:cx,cy,r` | `star:10,10,5:#ff0` |
| 心形 | `heart:cx,cy,s` | `heart:10,10,4:#f00` |
| 边框 | `frame:x,y,w,h` | `frame:1,1,18,18:#888` |
| 文本 | `text:x,y,字号:内容`（内容可含逗号，可选 `:#颜色`） | `text:10,10,1.5:Hi` / `text:10,10,1.5,Hi:#f00` |

- 坐标/颜色支持 `%值%` 引用（switch/变量/输入框实时更新）
- `show:画板id` / `hide:画板id` 操作联动开关显示
- `modal=1` 时渲染为按钮，点击弹窗显示画板

```markdown
[!房子](board:20|bg=#e0f2fe|id=house|shapes=rect:3,9,14,9:#eab308;triangle:2,9,18,9,10,2:#ef4444;rect:8,14,4,4:#7c3aed)
```

### 4.16 投票 `vote`

```
[!投票](vote:问题|选项1|选项2|...|id=名称|max=1|mode=bar)
```

| 参数 | 说明 | 示例 |
|------|------|------|
| 主参数 | `问题\|选项1\|选项2...`（第一个 `\|` 前是问题） | `vote:今晚玩什么?\|狼人杀\|UNO` |
| `id` | 投票标识（用于 localStorage 防重复） | `id=v1` |
| `max` | 最多可选几项（默认 1=单选） | `max=3` |
| `mode` | 显示模式（`bar` 进度条 / `list` 列表，默认 bar） | `mode=list` |

- 点击选项投票，再次点击取消；`max=1` 时切换选择，超出提示
- 已选状态 + 计数用 localStorage 记录（`lobby_vote_投票id`），**刷新不重置**
- 计数为本地消息级（多人真实统计需后端配合）

```markdown
[!投票](vote:今晚玩什么?|狼人杀|剧本杀|UNO|id=v1|max=1)
[!投票](vote:多选:喜欢哪些?|A|B|C|D|id=v2|max=3)
```

### 4.17 骰子 `dice`

```
[!掷骰](dice:表达式|id=名称)
```

| 参数 | 说明 | 示例 |
|------|------|------|
| 主参数 | 骰子表达式 `XdY±Z`（支持 `dY` 省略 X、纯数字） | `dice:2d6+3` |
| `id` | 结果存入变量（`%id%` 可引用） | `id=d1` |

- 支持 `1d20` / `2d6` / `3d6+2` / `d8` / `2d8-1` 等格式，非法格式回退 `1d6`
- 骰子数上限 100，防止刷屏
- 点击后显示每个骰子点数与总和，并写入变量供其他组件引用

```markdown
[!掷骰](dice:1d20|id=d20)
[!掷骰](dice:2d6+3|id=dmg)
[!显示结果](send:你掷出了 %d20%！)
```

### 4.18 定时到点 `at`

```
[!定时](at:HH:MM[:SS]|end=动作|id=名称|repeat=1)
```

| 参数 | 说明 | 示例 |
|------|------|------|
| 主参数 | 目标时间 `HH:MM` 或 `HH:MM:SS` | `at:21:30` |
| `end` | 到点执行的动作 | `end=send:开饭啦！` |
| `id` | 标识（可选） | `id=t1` |
| `repeat` | `repeat=1` 每天重复触发 | `repeat=1` |

- 渲染后实时显示剩余时间（每秒刷新）
- 已过今日的时间自动顺延到明天；到点执行 `end` 动作并显示「已触发」
- `repeat=1` 触发后自动重置，次日继续

```markdown
[!定时](at:21:30|end=send:⏰ 开饭啦！|id=dinner)
[!每日提醒](at:08:00:00|end=send:🌅 早上好！|repeat=1)
```

### 4.19 图集轮播 `gallery`

```
[!图集](gallery:标题|url1|url2|...|autoplay=秒数)
```

| 参数 | 说明 | 示例 |
|------|------|------|
| 主参数 | `标题\|图片URL列表`（第一个 `\|` 前是标题） | `gallery:风景\|https://x.com/a.png\|https://x.com/b.png` |
| `autoplay` | 自动轮播间隔秒数（默认 0=关闭） | `autoplay=3` |

- 图片 URL 必须通过白名单（png/jpg/gif/webp/bmp/svg/ico），非法链接整体显示 `[图集链接不合法]`
- 点击按钮弹窗轮播：左右箭头切换 + 指示点 + 页码 + 键盘 ←→ 切换
- 自动播放时用户手动切换会重置计时

```markdown
[!图集](gallery:旅行相册|https://x.com/1.png|https://x.com/2.jpg|https://x.com/3.webp|autoplay=3)
```

## 五、通用参数（任意类型可用）

| 参数 | 作用 | 示例 |
|------|------|------|
| `id=名称` | 组件唯一标识（消息内） | `id=foo` |
| `t=标题` | 附加标题（music 等） | `t=我的歌` |
| `init=值` | 初始值（var/def/input） | `init=0` |
| `color=前景色` | 前景色 | `color=#ff0000` |
| `color.bg=背景色` | 背景色 | `color.bg=#00ff00` |
| `perm=权限` | 权限（`@名` 白名单 / `!@名` 黑名单 / `@名=内容` 映射，逗号分隔） | `perm=@admin` |
| `sound=URL` | 点击音效（音频白名单同 music） | `sound=https://x.com/a.mp3` |
| `anim=秒数` | 点击动画时长 | `anim=3` |
| `click=规则` | 点击次数限制 | 见 5.1 |
| `on=动作` | 值变化联动 | `on=send:%sel%` |
| `lock=组名` | 倒计时锁定组 | `lock=quiz` |

### 5.1 点击次数 `click` 规则

| 写法 | 含义 |
|------|------|
| `click=5` | 全局共享 5 次 |
| `click=*5` | 每人独立 5 次 |
| `click=@张三:2` | 仅张三 2 次，其他人无限制 |
| `click=5@张三:2` | 全局 5 次 + 张三单独 2 次 |

## 六、值引用与表达式

### 6.1 引用
- `%名称%` 或 `{名称}`：引用输入框内容 / 变量值 / switch 当前值
- **默认值**：`%名称|默认值%` 或 `{名称|默认值}`，引用为空时返回默认值
```markdown
[!发送](send:我选了%choice%！)
[!发送](send:当前血量 %hp|100% / 100)
```

### 6.2 数学表达式（`set` 操作中自动求值）
- 仅支持 `数字 + - * / ( )`，非纯数字内容保持字符串
```markdown
[!加分](ok:q|right=set:score=%score%+10)
```

## 七、操作体系（统一 `操作名:参数`）

| 操作 | 说明 | 示例 |
|------|------|------|
| `send:内容` | 发送消息（支持 `%引用%`） | `send:你好%name%` |
| `copy:内容` | 复制内容 | `copy:文字` |
| `set:变量=值` | 设置变量（支持表达式） | `set:score=%score%+10` |
| `incr:变量` / `incr:变量=n` | 变量自增 | `incr:score=5` |
| `decr:变量` / `decr:变量=n` | 变量自减 | `decr:score` |
| `reset:输入框id` | 重置输入框 | `reset:name` |
| `switch:switch_id` | 切换可改变内容 | `switch:sel` |
| `close:` / `close:id` | 关闭交互区 / 指定组件 | `close:` |
| `bar.add:id=值` | 进度条增加 | `bar.add:bp=10` |
| `bar.sub:id=值` | 进度条减少 | `bar.sub:bp=10` |
| `bar.set:id=值` | 进度条设置 | `bar.set:bp=50` |
| `timer.start:id` | 启动倒计时 | `timer.start:t1` |
| `timer.stop:id` | 停止倒计时 | `timer.stop:t1` |
| `show:id` | 显示组件（画板等） | `show:map` |
| `hide:id` | 隐藏组件（画板等） | `hide:map` |
| `for:变量=起始;条件;步进;循环体` | for 循环（见 7.1） | `for:i=0;i<5;i+1;send:第%i%次` |

### 7.1 for 循环（安全限制）

格式：`for:变量=起始;条件;步进;循环体`

| 部分 | 说明 | 示例 |
|------|------|------|
| `变量=起始` | 循环变量及初始值（整数） | `i=0` |
| `条件` | `变量 运算符 数字`（`<` `<=` `>` `>=` `==` `!=`） | `i<5` |
| `步进` | `变量 运算符 数字`（`+` `-` `*` `/`） | `i+1` |
| `循环体` | 任意动作，可用 `%变量%` 引用当前值 | `send:第%i%次` |

**安全限制**：
1. **最高 300 次**，超出自动中断（兜底防线）
2. **禁止嵌套**（循环体内出现 `for:` 直接忽略）
3. **死循环方向检测**：上界条件（`<` `<=`）必须递增步进（`+` `*`），下界条件（`>` `>=`）必须递减步进（`-` `/`），方向矛盾（如 `i<5` 配 `i-1`）直接拒绝
4. **零值步进拦截**：步进为 `+0`/`-0`/`*1`/`/1`（变量不前进）直接拒绝
5. 条件/步进必须是 `变量 运算符 数字` 有界格式且变量名一致，杜绝死循环
6. **仅按钮触发**：只能写在按钮动作里（`right`/`wrong`/`on`/`cancel`/`close`/`hide`/`confirm` 等），消息渲染时不自动执行

示例：
```markdown
[!连发3条](cancel:for:i=0;i<3;i+1;send:消息%i%)
[!加分10次](cancel:for:i=0;i<10;i+1;incr:score=1)
[!进度+10](cancel:for:i=0;i<5;i+1;bar.add:bp=2)
```

**动作可组合**：`right` / `wrong` / `on` / `end` / `cancel` / `close` / `hide` 处填写的都是「操作」。

## 八、作用域

- 所有变量、输入框内容、switch 状态、倒计时、进度条，**仅当前消息内有效**。
- 不同消息之间互不影响，消息销毁状态自动回收。
- 弹窗（modal）内视作独立作用域，不共享外层消息状态。

---

## 九、安全规则

1. 所有展示文本必须 HTML 转义（`escapeHtml`）。
2. 图片 URL 仅允许 `http(s)` + 图片扩展名。
3. 音频 URL 仅允许 `http(s)` + 音频扩展名（见 4.9 白名单）。
4. 加密内容渲染时加密存储，避免明文暴露。
5. 数学表达式严格过滤（仅数字和运算符），杜绝注入。
6. 输入内容长度限制（消息最大 3500 字符，输入框值做截断）。

## 十、新旧语法对照（历史迁移参考）

> ⚠️ **旧语法自 v2 起已不再兼容**（代码中已移除），以下对照仅用于理解历史消息为何失效、以及如何改写。

| 旧语法 | 新语法 |
|--------|--------|
| `[!x](send:内容)` | `[!x](send:内容)`（不变） |
| `[!x](copy:内容)` | `[!x](copy:内容)`（不变） |
| `[!x](okbtn:foo\|right=..\|wrong=..)` | `[!x](ok:foo\|right=..\|wrong=..)` |
| `[!x](cancelbtn:动作)` | `[!x](cancel:动作)` |
| `[!x](closebtn:动作)` | `[!x](close:动作)` |
| `[!x](showif:foo=1\|content=..)` | `[!x](if:foo=1\|then=..)` |
| `[!x](randsend:..)` / `[!x](randmodal:..)` | `[!x](rand:..)` |
| `[!x](hidden:send:内容)` | `[!x](hide:send:内容)` |
| `[!x](input:..\|id:foo)` | `[!x](input:..\|id=foo)`（键值用 `=`） |
| `[!x](url::#f00;;@a^^5##3)` | `[!x](btn:url\|color=#f00\|perm=@a\|click=5\|anim=3)` |
| `{foo}` 引用 | `%foo%`（`{foo}` 仍兼容） |

## 十一、组合示例

**答题 + 计分 + 条件**
```markdown
[!定义](def:prize|init=🎁 大礼包)
[!变量](var:score|init=0)
[!输入](input:1+1=?|id=q1|ok=2)
[!确认](ok:q1|right=set:score=%score%+10|wrong=set:score=%score%)
[!满分](if:score=10|then=🎉 答对了，领取%prize%！)
[!发送](hide:send:我得了%score%分)
```

**倒计时 + 进度条 + 锁定**
```markdown
[!倒计时](timer:30|id=t1|lock=quiz|bar=bp|end=send:时间到！)
[!进度](bar:30/30|id=bp)
[!抢答](ok:q|right=send:我抢到了|wrong=send:请先输入|lock=quiz)
```

**联动 + 可改变**
```markdown
[!选择](switch:石头|剪刀|布|id=sel|on=send:你出了%sel%)
[!重置](cancel:reset:sel)
```
