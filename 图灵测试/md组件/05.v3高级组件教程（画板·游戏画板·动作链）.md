# 一、画板（纯展示）

## 1.1 是什么

画板 = 一个 **20×20 坐标系** 的绘图区，用坐标画直线/曲线/圆/矩形等图形。**纯展示**，不响应点击（要点击用游戏画板）。

## 1.2 基础语法

```
[!画板|图形序列|bg=色|grid=0|text=中央文字]
```

| 参数 | 说明 | 默认 |
|------|------|------|
| （第一段）尺寸 | 画板边长 1-20（数字） | 20 |
| 图形序列 | `;` 分隔的图形，无需 `shapes=` 前缀 | — |
| `bg=#fff` | 背景色 | 透明 |
| `grid=0` | 关闭网格辅助线 | 显示网格 |
| `text=文字` | 中央文本（`tx/ty/ts/tc` 覆盖位置/字号/颜色） | — |

**最短写法**（尺寸/背景/网格全省略）：

```md
[!画板|l:3,12,3,4;c:0,10,5,2,10,10]
```

## 1.3 图形类型全表

| 类型 | 语法 | 说明 |
|------|------|------|
| 线 | `l:x1,y1,x2,y2` | 直线 |
| 折线 | `p:x1,y1,x2,y2,...` | 多点折线（只写转折点） |
| 曲线 | `c:x1,y1,x2,y2,...` | 平滑曲线（Catmull-Rom 过所有点） |
| 圆 | `o:cx,cy,r` | 实心圆 |
| 矩形 | `r:x,y,w,h` | 实心矩形 |
| 点 | `d:x,y` | 小圆点 |
| 三角 | `t:x1,y1,x2,y2,x3,y3` | 实心三角形 |
| 心形 | `h:cx,cy,s` | 实心心形 |
| 多边形填充 | `pt:x1,y1,x2,y2,...:色` | 自动闭合+填充 |

**图形修饰**（追加在图形末尾，`|` 分隔）：

| 修饰 | 语法 | 说明 |
|------|------|------|
| 闭合填充 | `|f` / `|f00` / `|f#f00` | 折线/曲线闭合+填充（黑/红/显式色） |
| 线宽 | `|wN` | N 倍线宽（基础 0.12 单位） |

## 1.4 基础示例

```md
# 一条直线
[!画板|l:2,2,18,18]

# 圆 + 矩形 + 三角（无网格）
[!画板:10|o:5,5,2:f00;r:1,1,3,3;t:8,2,9,2,8.5,3|grid=0]

# 心形 + 折线 + 填充曲线
[!画板|h:10,10,3:f00;c:2,10,5,5,8,8|f;pt:14,4,16,6,15,8,13,7:f00]

# 带背景 + 中央文字
[!画板:10|r:0,0,10,10:#ffe;o:5,5,3:f00|bg=#fff|text=你好|ts=2|tc=#f00]
```

## 1.5 简化三原则（省字数）

1. **曲线代多线**：1 条 `c:` 表达任意平滑轮廓，替代 N 段直线
2. **折线合并段**：连续直线段合成 1 条 `p:`，只写转折点
3. **闭合自动补**：`|f` 自动闭合，终点不必重复首点

```md
# ❌ 直线版（6 段弧 = 6 个 l:，71 字符）
[!画板|l:2,10,3,7;l:3,7,5,5;l:5,5,8,4;l:8,4,11,5;l:11,5,13,7;l:13,7,14,10]

# ✅ 曲线版（1 条 c:，39 字符，省 45%）
[!画板|c:2,10,3,7,5,5,8,4,11,5,13,7,14,10]
```

## 1.6 动态画板（`{名}` 实时引用）

画板图形参数支持 `{名}` 引用，变量/开关/输入变化时**自动重绘**：

```md
[!开关:#f00/#00f|id=颜色|颜色=1]
[!变量:圆x=5]
[!画板:10|o:{圆x},5,2:{颜色}|grid=0]
[!按钮:右移|变量:圆x={圆x}+1]
[!按钮:左移|变量:圆x={圆x}-1]
```

点「右移/左移」→ 圆的位置实时变化；点「颜色开关」→ 圆变色（开关值直接当颜色）。

```md
# 进度圆环（配合进度条）
[!进度:6/10|id=血]
[!画板:10|o:5,5,4;o:5,5,{血}/10*4:00f00|grid=0]
```

> `{血}/10*4` 是数学表达式：进度值 / 最大 × 半径，血条变圆环！

## 1.7 常见坑

| 坑 | 说明 |
|----|------|
| 坐标超界 | 坐标 0~尺寸（默认 0~20），超出被裁剪 |
| 颜色写法 | 图形颜色 `:f00`（不用 `#`）；`|f00` 是填充 |
| `|f` 位置 | 修饰段必须在图形坐标之后：`c:...|f` |
| 中文乱码 | 画板不画文字，用 `text=` 参数显示中央文字 |
| v2 兼容 | 画板是唯一 v2/v3 双兼容组件：`[!开图](board:20|shapes=line:...|modal=1)` 仍可用（自动转换） |

# 二、游戏画板（可点击）

## 2.1 与画板的区别

| | 画板 | 游戏画板 |
|---|------|---------|
| 展示 | ✅ | ✅（继承全部能力） |
| 点击 | ❌ 纯展示 | ✅ 点击触发动作 |
| 内置变量 | 无 | `{点击x}{点击y}{点击格}` |
| 适用 | 配图/示意图 | 打地鼠/井字棋/扫雷/迷宫 |

## 2.2 基础语法

```
[!游戏画板:尺寸|图形序列|点击=动作|bg=色|grid=0]
```

## 2.3 两种点击方式

### ① 组件级点击（整板统一动作）

```md
[!游戏画板:3|o:0.5,0.5,0.4:f00|点击=发送:你点到了画板！]
```

点画板**任意位置**都触发同一个动作，可用 `{点击格}` 区分点了哪格。

### ② 图形级热点（每个图形独立动作）

```md
[!游戏画板:3|r:0,0,1,1@点击=发送:点了左上格;r:1,0,1,1@点击=发送:点了上中格;r:2,0,1,1@点击=发送:点了右上格]
```

每个图形带自己的 `@点击=动作`（与 `|f`、`|wN` 修饰并列），点中该图形只触发它自己的动作。

## 2.4 内置变量（点击时自动注入）

| 变量 | 含义 | 例子（3x3 板） |
|------|------|----------------|
| `{点击x}` `{点击y}` | 点击位置坐标（0~尺寸） | 点左上格 → 0~1 |
| `{点击格}` | 网格编号：`floor(y)×尺寸+floor(x)+1` | 左上=1，右下=9 |

```md
# 点哪格就报哪格
[!游戏画板:3|点击=发送:你点了第 {点击格} 格（坐标 {点击x},{点击y}）]
```

## 2.5 触发规则

1. 点中**图形热点** → 只执行该图形动作（图形级优先，不双触发）
2. 未命中图形 → 有组件级 `点击=` 则执行组件级
3. 图形级命中时，`{点击x}{点击y}{点击格}` 同样注入
4. 没有 `点击=` 的板子 = 纯展示画板

## 2.6 实战：打地鼠（点击判定）

```md
[!变量:分数=0]　得分：[!显示:分数]
[!变量:地鼠=1,3,5,7,9]
[!按钮:🎲 随机地鼠|变量:地鼠=1,3,5,7,9&洗牌:地鼠,取3]　🐹 地鼠在：[!显示:地鼠]
[!游戏画板:3|点击=变量:分数={分数}+10?{地鼠}~{点击格}:发送:打空了！]
```

**核心**：`{地鼠}~{点击格}` = 地鼠列表包含点击格 → 打中 +10，否则打空。

## 2.7 实战：井字棋（图形热点落子）

```md
[!变量:棋1=·] [!变量:棋2=·] [!变量:棋3=·]
[!变量:棋4=·] [!变量:棋5=·] [!变量:棋6=·]
[!变量:棋7=·] [!变量:棋8=·] [!变量:棋9=·]
[!变量:我方=X]　[!显示:棋1][!显示:棋2][!显示:棋3]
[!显示:棋4][!显示:棋5][!显示:棋6]
[!显示:棋7][!显示:棋8][!显示:棋9]
[!游戏画板:3|r:0,0,1,1@点击=变量:棋1={我方}?{棋1}=·:发送:有子了;r:1,0,1,1@点击=变量:棋2={我方}?{棋2}=·:发送:有子了;r:2,0,1,1@点击=变量:棋3={我方}?{棋3}=·:发送:有子了;r:0,1,1,1@点击=变量:棋4={我方}?{棋4}=·:发送:有子了;r:1,1,1,1@点击=变量:棋5={我方}?{棋5}=·:发送:有子了;r:2,1,1,1@点击=变量:棋6={我方}?{棋6}=·:发送:有子了;r:0,2,1,1@点击=变量:棋7={我方}?{棋7}=·:发送:有子了;r:1,2,1,1@点击=变量:棋8={我方}?{棋8}=·:发送:有子了;r:2,2,1,1@点击=变量:棋9={我方}?{棋9}=·:发送:有子了]
```

> 9 个格子各自热点，条件动作判定"空格才落子"，`[!显示]` 实时刷新棋盘。

## 2.8 常见坑

| 坑 | 说明 |
|----|------|
| 网格编号 | 按**每单位一格**算：尺寸 3 → 1~9，尺寸 20 → 1~400 |
| 图形热点覆盖 | 后画的图形盖住先画的，点击命中**最上层**图形 |
| 双触发 | 图形级命中时不触发组件级（只有未命中图形才走组件级） |
| 点击空白 | 无图形热点的空白区域 → 走组件级 `点击=`；都没有则无反应 |
| 线/点的命中 | 细线/点难点中，建议热点用矩形/圆（加大命中区） |

# 三、动作链（隐形编排器）

## 3.1 是什么

动作链 = **隐形动画/操作编排器**。前端不显示任何东西（类变量），按时间顺序自动操作其他组件：移动、变色、改文字、更新画板、执行任意动作，可循环、可被外部触发。

## 3.2 基础语法

```
[!动作链:步骤1/步骤2/步骤3|循环=N|id=名|绑定=1]

步骤 = 目标=组件id;操作;操作;...;延时=毫秒;条件=表达式;跳转=步骤号（步骤内用 `;` 分隔，与组件参数 `|` 区分）
```

- **`/`** 分隔步骤
- **`|`** 分隔步骤内参数
- **`延时=毫秒`**：该步执行后等待的毫秒数（1 秒 = 1000）
- 步骤串写在第一个裸参数，链级参数（循环/id/绑定）放后面

## 3.3 双 ID 机制

```
[!动作链:目标=标题;闪烁=3;延时=200|id=开场|绑定=1]
            └──── 目标组件 id ────┘   └─ 链 id ─┘
```

| ID | 作用 | 写法 |
|----|------|------|
| **目标组件 id** | 匹配要操作的组件 | 组件统一 `id=`（如 `[!文本:标题|id=标题]`） |
| **链 id** | 动作链对外接口 | `id=链名` |

```md
[!文本:👑 标题|id=标题]                    ← 目标组件挂 id
[!动作链:目标=标题;颜色=#f00;延时=300|id=变色]  ← 链自身 id
```

### 3.3.1 弹窗内组件定位（x/y 参数，v3.5 新增）

弹窗内所有组件支持 `x=数字` / `y=数字` 参数，**相对自身流位置偏移 px**（不挤开其他组件），手机/电脑相对位置一致：

```
[!按钮:🌟|id=星|x=10|y=5]      ← 按钮右移 10px、下移 5px
[!文本:提示|#f00|x=-8|y=2]     ← 支持负值
```

- 仅弹窗/消息内组件有效（渲染时注入 `position:relative; left/top`）
- 与动作链 `移动x/y`（transform 动画）**互不干扰**：x/y 是静态定位，移动是动态动画

## 3.4 步骤操作集全表

| 操作 | 说明 | 示例 |
|------|------|------|
| `移动x=1` / `移动y=5` | 位移动画（px） | `目标=鼠;移动x=30;延时=400` |
| `缩放=1.2` | 缩放动画 | `目标=图;缩放=1.5;延时=200` |
| `旋转=45` | 旋转动画（**累积增量**，每次 +45°，持续旋转不跳回） | `目标=图;旋转=90;延时=300` |
| `透明=0.3` | 透明度 0~1（配合隐藏做淡入淡出） | `目标=弹;透明=0;延时=500` |
| `闪烁=2` | 闪烁 N 次 | `目标=标题;闪烁=3;延时=200` |
| `颜色=#f00` | 改颜色 | `目标=标题;颜色=#f00;延时=300` |
| `文字=新内容` | 改显示文字 | `目标=提示;文字=倒计时 3!;延时=1000` |
| `隐藏` / `显示` | 组件显隐 | `目标=面板;隐藏` |
| `状态=值` | 设置组件状态（开关/变量/进度） | `目标=血;状态=3` |
| `变量=名=值` | 设置任意变量 | `目标=x;变量=分数=100` |
| `音效=URL` | 播放音效 | `目标=x;音效=https://.../ding.mp3` |
| `更新=图形序列` | **画板/游戏画板**：替换图形重绘 | `目标=板;更新=o:1.5,1.5,0.4:f00` |
| 裸 `更新` | 仅触发重绘（重新解析 `{名}`） | `目标=板;更新` |
| 任意 v3 动作 | 直接写动作 | `发送:行动！`、`随机:骰=1,6`、`弹窗:标题|内容` |

## 3.5 循环

| 写法 | 含义 |
|------|------|
| （省略） | 单次 |
| `循环` | **无限循环**（所在消息可见才跑，划出视口暂停） |
| `循环=3` | 循环 3 次 |

```md
# 无限左右跳（消息可见时一直跑）
[!动作链:目标=鼠;移动x=30;延时=400/目标=鼠;移动x=-30;延时=400|循环]

# 循环 3 次闪烁
[!动作链:目标=标题;闪烁=1;延时=300|循环=3]
```

> ⏸ 消息滚出屏幕 → 链暂停；滚回来 → 继续。无限循环不会一直耗资源（不可见即停）。

## 3.6 触发与控制

| 触发方式 | 写法 |
|---------|------|
| 自动触发 | 省略 `绑定=`（渲染后开始） |
| 绑定启动 | `绑定=1` + 按钮 `动作链:名,开始` |
| 倒计时/定时触发 | `end=动作链:名,开始` |
| 开关联动 | `[!开关:开/关|on=动作链:名,开始]` |
| 确认触发 | `[!确认:确定？|动作链:名,开始]` |
| 条件动作触发 | `动作链:名,开始?{金币}>100` |
| **链间联动** | 步骤里 `执行=动作链:名2,开始` |

**控制动作**：

```
动作链:名,开始   动作链:名,暂停   动作链:名,继续   动作链:名,停止   动作链:名,重播
```

```md
[!动作链:目标=鼠;移动x=30;延时=400|循环|id=跳动]
[!按钮:⏸ 暂停|动作链:跳动,暂停]
[!按钮:▶️ 继续|动作链:跳动,继续]
[!按钮:⏹ 停止|动作链:跳动,停止]
[!按钮:🔁 重播|动作链:跳动,重播]
```

## 3.7 步骤高级控制

### 条件步骤（不满足跳过）

```md
# 血量 <30 才触发警报，否则跳过
[!动作链:目标=警报;条件={血量}<30;闪烁=3;延时=200/目标=警报;隐藏|循环]
```

### 跳转（goto）

```md
# 条件满足直接跳第 3 步（闪烁），跳过中间位移动画
[!动作链:目标=板;条件={跳过}=1;跳转=3/目标=板;移动x=10;延时=300/目标=板;移动y=10;延时=300/目标=板;闪烁=2;延时=200]
```

## 3.8 动画节奏技巧

```md
# 开场倒计时（文字逐秒变化）
[!文本:3|id=倒|大]
[!动作链:目标=倒;文字=2;延时=1000/目标=倒;文字=1;延时=1000/目标=倒;文字=GO!;颜色=#f00;延时=1000/目标=倒;隐藏|id=开场|绑定=1]
[!按钮:🚀 开始|动作链:开场,开始]

# 敌人受击抖动（连串快速位移）
[!动作链:目标=敌;移动x=5;延时=60/目标=敌;移动x=-10;延时=60/目标=敌;移动x=5;延时=60/目标=敌;移动x=-5;延时=60|id=受击|绑定=1]
[!按钮:⚔️ 攻击|动作链:受击,开始]

# 淡入淡出提示
[!文本:💡 提示|id=提示|透明=0]
[!动作链:目标=提示;透明=1;延时=500/目标=提示;透明=0;延时=500|循环|id=呼吸|绑定=1]
[!按钮:✨ 显示提示|动作链:呼吸,开始]
```

## 3.9 常见坑

| 坑 | 说明 |
|----|------|
| 目标不存在 | `目标=xxx` 但消息里没有 `id=xxx` 组件 → 该步静默跳过 |
| 目标 id 冲突 | 同一消息内 id 必须唯一（后渲染覆盖前者） |
| 延时单位 | **毫秒**！`延时=1` 是 1ms 不是 1 秒 |
| 无限循环 | 只有 `循环`（无数字）才无限；消息划出视口自动暂停 |
| 链间防环 | 禁止 A 链触发 B 链再触发 A 链（防死循环） |
| 可见性 | 链在**后台/切走**时暂停，回来继续（和倒计时一致） |
| 文字/状态 | `文字=` 改显示，`状态=` 改开关/变量/进度值，别混用 |
