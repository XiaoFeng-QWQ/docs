## 🔘 第2条：按钮 / 动作按钮
```md
[!按钮:跳转百度|https://www.baidu.com]
[!复制:复制验证码|ABC-2026-8888]
[!发送:收到|收到，谢谢！]
[!按钮:掷骰|随机:骰=1,6&发送:🎲 你掷出了 {骰} 点]
[!按钮:抽签|洗牌:名单,取1&发送:🎯 抽到 {名单}]
```

## 📄 第3条：弹窗按钮（含图片+嵌套）

## ⚠️ 第4条：确认 / 开关 / 显示 / 条件
```md
[!确认:确定删除？|发送:已确认删除]
[!开关:开/关|id=灯|on=发送:灯被切到 {灯}]
[!输入:输入昵称|id=昵称]　你好，[!显示:昵称]
[!条件:{昵称}|✅ 已输入昵称]
[!变量:金币=100]　金币：[!显示:金币]　[!条件:{金币}>50|💰 有钱人]
```

## 🎲 第5条：骰子（随机动作实现）
```md
[!变量:总=0]
[!按钮:🎲 掷 1d6|随机:骰=1,6&发送:🎲 你掷出了 {骰} 点]
[!按钮:🎲 掷 2d6|随机:骰1=1,6&随机:骰2=1,6&变量:总={骰1}+{骰2}&发送:🎲 {骰1} + {骰2} = {总}]
[!按钮:🎯 1d20 判定|随机:判定=1,20&发送:🎯 检定结果：{判定}（>=15 成功）]
[!条件:{判定}>=15|✅ 成功！]
[!条件:{判定}<15|❌ 失败...]
```

## ✂️ 第6条：猜拳（随机 + 条件动作）
```md
[!按钮:✌️ 剪刀|随机:电脑=1,3&发送:🤖 电脑出剪刀 → 🤝 平局?{电脑}=1:发送:🤖 电脑出石头 → 💔 你输了?{电脑}=2:发送:🤖 电脑出布 → 🎉 你赢了]
[!按钮:✊ 石头|随机:电脑=1,3&发送:🤖 电脑出石头 → 🤝 平局?{电脑}=2:发送:🤖 电脑出布 → 💔 你输了?{电脑}=3:发送:🤖 电脑出剪刀 → 🎉 你赢了]
[!按钮:🖐 布|随机:电脑=1,3&发送:🤖 电脑出布 → 🤝 平局?{电脑}=3:发送:🤖 电脑出剪刀 → 💔 你输了?{电脑}=1:发送:🤖 电脑出石头 → 🎉 你赢了]
```
> 规则：1=剪刀 2=石头 3=布，随机数由 `{电脑}` 变量驱动，条件动作三层嵌套判定胜负。

## 🔐 第7条：点击限制（每人一次 / 所有人一次）
```md
# 按钮只能点一次（每人独立）
[!按钮:✋ 签到|发送:✅ 签到成功！|click=*1]

# 按钮限制所有人只能点一次（全局共享）
[!按钮:🧨 抢头彩|发送:我是第一个抢到的！|click=1]

# 答题：每人 3 次机会
[!按钮:🔍 看答案|弹窗:📖 答案|42|click=*3]
```

## 🎮 第8条：游戏画板（可点击）
```md
[!变量:分数=0]　得分：[!显示:分数]
[!游戏画板:3|o:0.5,0.5,0.4:f00|点击=变量:分数={分数}+10?{地鼠}~{点击格}:发送:打空了！]
[!变量:地鼠=1,3,5,7,9]
[!按钮:🎲 随机地鼠|变量:地鼠=1,3,5,7,9&洗牌:地鼠,取3]
```
> 点画板格子：点中地鼠格（`{点击格}` 在 `{地鼠}` 列表里）→ +10 分，否则提示打空。

## ⛓ 第9条：动作链（隐形动画）
```md
[!文本:🦔 地鼠出没|id=鼠]
[!动作链:目标=鼠;移动x=30;延时=400/目标=鼠;移动x=-30;延时=400|循环|id=跳动]
[!按钮:⏸ 暂停|动作链:跳动,暂停]
[!按钮:▶️ 继续|动作链:跳动,继续]
```

## 🕵️ 第10条：谁是卧底模板（改玩家名和词即可玩）
```md
[!变量:玩家=小攸/小喵/小汪/小明/小红]
[!变量:身份=平民/平民/平民/平民/卧底]
[!变量:平民词=牙膏]
[!变量:卧底词=洗面奶]
[!按钮:🎭 发牌|洗牌:身份&弹窗:🕵️ 身份表|{玩家}→{身份}\n📝平民词：{平民词}\n🕵️卧底词：{卧底词}]
[!倒计时:30秒|id=轮次|绑定=1|end=发送:🔄 下一位描述！]
[!投票:🕵️ 这轮投谁|{玩家}]
[!按钮:🚨 卧底被投出|发送:🏆 平民胜利！卧底「{卧底词}」被揪出来了！]
```
> 修改 `{玩家}` 名单即可开局；`{身份}` 与玩家数量保持一致；点「发牌」随机洗牌身份并显示平民词/卧底词；投票选项自动从名单展开。
