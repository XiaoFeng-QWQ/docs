# MD 按钮功能文档（聊天室）

所有按钮语法：`[!按钮文字](类型:参数)`，按钮文字前必须带 `!`。

---

## 一、按钮类型（5 种）

### 1. 跳转按钮
```
[!跳转百度](https://www.baidu.com)
```
点击后**新窗口打开**链接。

### 2. 复制按钮
```
[!复制邀请码](copy:ABC123456)
```
点击后**复制**指定文本到剪贴板，并弹出提示。

### 3. 快捷发送按钮
```
[!回复收到](send:收到，谢谢！)
```
点击后**自动发送**指定内容到聊天室。

### 4. 弹窗按钮
```
[!查看说明](modal:标题|内容)
```
点击弹出**弹窗**，标题显示在黄色标题栏，内容支持完整 MD 渲染：
- 粗体 `**加粗**`、斜体、代码、表格、列表、引用
- **图片**：`![描述](图片URL)`（仅弹窗内支持，自动缩放居中，最大不超弹窗）
- **嵌套按钮**：内容里可以再放任意按钮（弹窗套弹窗）

### 5. 网页内嵌按钮
```
[!内嵌百度](embed:https://www.baidu.com)
```
点击弹出大弹窗，**iframe 内嵌加载**指定网页。

## 二、通用参数

### 颜色参数（`::文本色|按钮色`）
16 进制，带不带 `#` 都行；按钮色填 `-1` 为**透明按钮**（只显示黑边+文本）。
```
[!红色按钮](https://www.baidu.com::ffffff|ff0000)   ← 白字红底
[!透明按钮](https://www.baidu.com::-1)               ← 透明（黑边+黑字）
[!透明红字](copy:内容::ff0000|-1)                    ← 透明底红字
[!弹窗自定义色](modal:标题|内容::ffffff|3366ff)      ← 弹窗按钮也支持
```

### 权限参数（`;;` 后，逗号分隔）
```
;;@名字                 → 白名单：只有这些名字可点
;;!@名字                → 黑名单：这些名字点了没效果
;;@名字=内容            → 按人显示：该名字看到/触发指定内容
```
```
[!仅小明可用](send:只有小明能发的;;@小明)
[!小红不可用](copy:通用;;!@小红)
[!按人显示](modal:默认标题|默认内容;;@小明=小明的标题|给小明的内容,@小红=给小红的内容)
```

### 颜色 + 权限组合
```
[!组合示例](send:内容::ffffff|ff0000;;@小明)
```

## 三、嵌套与限制

| 项目 | 说明 |
|------|------|
| 嵌套 | 弹窗内容可放任意按钮（弹窗内嵌弹窗/网页/复制/发送） |
| 弹窗上限 | 同时最多 **10 个**，超限提示 |
| 消息内图片 | ❌ 禁止（防流量攻击），仅弹窗内允许 |
| 图片安全 | 懒加载 + 不泄露来源 + 尺寸封顶 + 坏图自动隐藏 |
| 禁用按钮 | 白名单/黑名单不满足时按钮**灰色禁用**，点击提示无权限 |

## 四、完整示例

```markdown
[!跳转](https://www.baidu.com) [!复制](copy:TEST-2026) [!发送](send:收到！) 
[!内嵌](embed:https://www.baidu.com) 
[!弹窗](modal:📖 说明|**欢迎**！这是弹窗：
![图片](https://example.com/pic.jpg)
点这里 [!内嵌百度](embed:https://www.baidu.com) 或 [!复制码](copy:8888))
[!彩色弹窗](modal:🎨|自定义颜色弹窗::ffffff|3366ff)
[!仅管理员](send:管理员专属消息;;@admin)
```
